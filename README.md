# 📊 Análise de Clientes e Vendas com SQL

## Sobre o projeto

Projeto de portfólio desenvolvido para praticar SQL aplicado a um cenário fictício de uma empresa do setor financeiro.

O objetivo é analisar o perfil dos clientes e o desempenho das vendas, utilizando SQL para transformar dados em informações relevantes para o negócio.

## 🎯 Objetivos

- Analisar o perfil dos clientes
- Identificar diferenças entre cidades
- Analisar o faturamento por produto
- Identificar clientes com maior volume de compras
- Calcular ticket médio
- Praticar consultas SQL aplicadas a perguntas de negócio

## 🛠️ Tecnologias e conhecimentos

- SQL
- SELECT
- WHERE
- INNER JOIN
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- ORDER BY
- LIMIT

## 🔎 Análises realizadas

1. Quantidade de clientes por cidade
2. Salário médio por cidade
3. Total gasto por cliente
4. Faturamento total por produto
5. Clientes que gastaram mais de R$ 800
6. Cliente com maior número de compras
7. Produto com maior ticket médio

## 📈 Principais resultados

- Rio de Janeiro possui 4 clientes na base.
- Niterói e São Paulo possuem 3 clientes cada.
- São Paulo apresenta o maior salário médio entre as cidades analisadas.
- Ana possui o maior total gasto, com R$ 1.300.
- Seguro apresenta o maior faturamento total, com R$ 2.100.
- Ana realizou o maior número de compras, com 2 compras.
- Consórcio apresenta o maior ticket médio, de R$ 1.000.

## 💡 Conclusão

A análise demonstra como consultas SQL podem ser utilizadas para transformar dados de clientes e vendas em informações úteis para apoiar análises de negócio.

Este projeto faz parte do meu desenvolvimento na área de Análise de Dados e representa minha prática com SQL, agregações, agrupamentos, filtros e relacionamentos entre tabelas.
